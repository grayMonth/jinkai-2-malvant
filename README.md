# SECURE SHIFT

セキュリティインシデント対応をロールプレイ形式で学ぶ、教育用の防御シミュレーションゲームです。

- フロントエンド: React + TypeScript + Vite
- バックエンド: Python + FastAPI（静的 JSON シナリオの配信のみ、DB なし）
- Docker Compose で両者をまとめて起動可能

## ゲーム概要

プレイヤーは企業の情報システム部門のセキュリティ対応担当者となり、社員からの報告やログをもとに、インシデントの各局面でどう対応するかを選択していきます。選んだ対応によって被害の広がり方や結末が変化し、対応に唯一の正解はないという、インシデントレスポンスの難しさを体感できる構成になっています。

## ゲームシステム

### 進行の仕組み

各シナリオは、状況説明・社員からの報告・ログなどのエビデンスとともに提示される複数の局面（ノード）で構成されています。プレイヤーは局面ごとに用意された選択肢から1つを選び、その結果として次の局面、またはエンディングへ進みます。選択後にはその対応の解説（rationale）が表示され、結果画面ではエンディングの総評に加えて、実際に選んだ枝・選ばなかった枝・推奨ルートとの比較を振り返ることができます。

### 4指標

選択の結果は、以下 4 つの指標の増減として蓄積されます（初期値は 0）。指標はゲージとして常時表示されますが、値そのものはエンディングの判定には使用しません。

| 指標 | 内容 |
| --- | --- |
| containment | 封じ込め（被害拡大の抑止） |
| service | サービス影響（業務・利用者への影響） |
| trust | 信頼（社内外からの信頼度） |
| fatigue | 疲労（対応にかかる負荷） |

### エンディング判定

エンディングは、指標の値ではなく選択の履歴（各選択肢に付与された `rank`）によって判定されます。

1. **Bad End**：`bad` を1つでも選んだ時点で即時終了
2. **True End**：最後まで到達し、すべての選択が `recommended` だった場合
3. **Normal End**：上記いずれにも該当しない場合

### 収録シナリオ

| ファイル | タイトル | 想定インシデント |
| --- | --- | --- |
| `scenario-01.json` | ランサムウェア感染対応シミュレーション | 感染端末を起点とした被害拡大の防止・証拠保全・影響範囲の把握・復旧判断 |
| `scenario-02.json` | クラウドアカウント侵害対応シミュレーション | クラウドアカウント侵害を想定した、アカウント保護・不正セッションの遮断・監査ログ調査・関係者連携 |
| `scenario-03.json` | DDoS攻撃対応シミュレーション | L7 DDoS発生時のトリアージ・緩和策の選定・対外対応、可用性攻撃が侵入の陽動として使われるケースの見極め |

## 起動方法

リポジトリをクローンし、フロントエンドに `.env` を用意したうえで Docker Compose を起動するだけで、フロント・バックエンドがまとめて立ち上がります。

```sh
git clone <このリポジトリのURL>
cd cyber-triage

# フロントエンドの環境変数ファイルを用意
cp frontend/.env.example frontend/.env

# フロント・バックエンドを一括起動
docker compose up -d --build
```

起動後のアクセス先は以下の通りです。

| サービス | URL |
| --- | --- |
| フロントエンド | http://localhost:3000 |
| バックエンド API | http://localhost:8000 |
| Swagger UI | http://localhost:8000/docs |
| ヘルスチェック | http://localhost:8000/health |

`docker-compose.yml` では、バックエンドのヘルスチェックが通ってからフロントエンドが起動する設定になっています。`frontend/.env` には最低限次の内容が必要です。

```dotenv
VITE_DATA_SOURCE=api
VITE_API_BASE_URL=http://localhost:8000
```

停止する場合は `docker compose stop` を、削除する場合は `docker compose down` 実行してください。
